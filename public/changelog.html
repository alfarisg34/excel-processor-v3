Aturan Semantic Versioning (SemVer 2.0.0)

Sistem penomoran versi X.Y.Z (Major.Minor.Patch) digunakan untuk menjamin kejelasan dampak perubahan terhadap pengguna dan sistem lain:

MAJOR (X)
Perubahan Fundamental / Breaking Changes

Dinaikkan saat terjadi perombakan struktur atau format data yang tidak kompatibel ke belakang. File format lama tidak dapat diproses lagi tanpa penyesuaian.
Contoh: Migrasi arsitektur dari V2 ke V3, perombakan besar engine formula.

MINOR (Y)
Penambahan Fitur Baru (Backward-Compatible)

Dinaikkan saat menambahkan fitur atau fungsionalitas baru yang tetap kompatibel dengan data lama.
Contoh: Modul Rekap Hirarki (Alur 3), dukungan sumber dana PLN/PHLN, penambahan 3 kolom summary baru (Kolom 55-57), dropdown multi-select akun.

PATCH (Z)
Perbaikan Bug & Penyesuaian Minor

Dinaikkan saat memperbaiki kesalahan bug, regex, atau penyesuaian label tanpa memodifikasi kontrak fungsional.
Contoh: Akomodasi subkomponen multi-karakter (AC, ZA, ZB), koreksi marker blokir RK vs Blokir Kode A, harmonisasi narasi label.
